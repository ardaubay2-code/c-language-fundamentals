\# C Language Fundamentals



This repository contains basic to intermediate level exercises and algorithmic projects implemented in the C programming language, focusing on arrays, matrices, pointers, and file handling.



\## Projects



| # | Project Name | Folder | Description |

|---|---|---|---|

| 1 | \*\*Sieve of Eratosthenes\*\* | \[`sieve-of-eratosthenes/`](./sieve-of-eratosthenes) | Finds all prime numbers between 2 and 999 using a boolean flag array. |

| 2 | \*\*Craps Game\*\* | \[`craps-game/`](./craps-game) | Simulates 10,000 games of Craps to analyze win/loss distribution, win rate, and average game duration. |

\*More projects will be added soon.\*



\## How to Compile and Run





(for example:)





Navigate to the project directory and compile the source file using `gcc`:



```bash

cd sieve-of-eratosthenes

gcc sieve.c -o sieve

./sieve

```
